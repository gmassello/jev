01 · qué es

Le das un texto y preguntas cerradas; devuelve respuestas tipadas

// entrada state: "El televisor llegó con la pantalla partida..." questions: { refund: { type: 'boolean', instructions: '¿Pide reembolso?' } }
// salida: un objeto, no texto answers: { refund: { probability: 0.98 } } usage: { inputTokens: ~400 }

Sin prompt engineering de formato ni parseo: el tipo de la respuesta lo fija la pregunta.

03 · system one

Pensar rápido, pensar despacio

Sistema 1 · Jev

Rápido, automático, un juicio de un vistazo.

"¿Este cliente está enojado?"

Sistema 2 · LLM

Lento, deliberado, paso a paso.

"Calculá el reintegro con estas tres reglas."

Kahneman describe dos modos de pensar. Muchas decisiones de un sistema son de Sistema 1, y pagar Sistema 2 por cada una es caro y lento.

04 · tipos de pregunta

Tres tipos, tres formas de respuesta

boolean

¿El cliente pide un reembolso?

→ probability: 0.98

choice

¿A qué área va? facturación, envíos, técnica o cuenta

→ choice: "envios" + probabilities

score

¿Qué tan urgente es? baja, media, alta

→ score: Σ i·p(i), desde 0

Una pregunta = una sola cosa. Opciones que no se pisen. Niveles de menor a mayor.

08 · integración

Tres pasos

  • Key de AI Gateway en AI_GATEWAY_API_KEY
  • npm i ai@7.0.113
  • Llamar a experimental_evaluate
import { experimental_evaluate as evaluate } from 'ai'; const { answers } = await evaluate({ model: 'typesafe-ai/jev', state: ticketText, questions: { urgent: { type: 'boolean', instructions: 'Is this ticket urgent?' }, }, }); if (answers.urgent.probability > 0.9) escalate();
