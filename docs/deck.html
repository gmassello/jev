Qué es Jev

Un modelo que evalúa, no que conversa

Le das un texto y una pregunta cerrada, y te devuelve una respuesta con su probabilidad.

Sí / No

Una probabilidad de 0 a 1 de que sea "sí".

Opción

Una de tu lista, con el reparto de probabilidad entre todas.

Escala

Un nivel ordenado, con la probabilidad de cada uno.

TypeSafe lo llama el primer modelo System One, por Kahneman: decide rápido, como el Sistema 1, en vez de razonar en voz alta como un LLM.

Lo ofrece TypeSafe por Vercel AI Gateway (typesafe-ai/jev).

Jev y un LLM

Si la salida es una decisión cerrada, Jev. Si es texto libre, un LLM. Si es una regla fija, código.

Otro número: qué tan concentrada está la distribución. 1 si casi todo va a una opción, 0 si está pareja.

Probabilidad debajo de 0,9 → el ticket va a revisión humana.

Impacto

Lo obvio sale solo; la duda va a una persona

Hoy

100 %

Una persona lee cada ticket, cada falla y cada defecto, aunque la mayoría sean obvios.

Con Jev y umbral 0,9

5 de 5

tickets claros se rutean solos; el ambiguo queda debajo del umbral en cada corrida y va a revisión.

Son 5 tickets de prueba, no una estadística: con datos reales el porcentaje se mide.

Riesgos

Antes de producción

  • El texto que entra no es de confianza. Tratalo como dato, nunca como instrucción, y no automatices una acción irreversible.
  • Jev prefiere la primera opción cuando duda. Probá tus preguntas con las opciones en otro orden.
  • Números, fechas y conteos se resuelven en código. "¿Pasaron más de 30 días?" se calcula.
  • Las probabilidades no vienen calibradas. Medí con tus propios casos dónde poner el umbral.

La key vive en el server, nunca en el navegador ni en el repo.

Integración

Una llamada del AI SDK

npm i ai@7.0.153
export AI_GATEWAY_API_KEY=...

import { experimental_decide as decide } from 'ai';

const { answers } = await decide({
  model: 'typesafe-ai/jev',
  state: 'No puedo entrar a mi cuenta desde ayer: me dice que la contraseña es incorrecta.',
  questions: { area: { type: 'choice', instructions: '¿A qué área va este ticket?',
    criteria: { facturacion: 'Cobros, facturas y reintegros', tecnica: 'Errores de la web o de la app',
      cuenta: 'Acceso, seguridad y datos de la cuenta' } } },
});

const { choice, probabilities } = answers.area;
if (probabilities[choice] >= 0.9) console.log('Rutear a', choice);
else console.log('A revisión humana:', probabilities);

Arquitectura

La key nunca llega al navegador

Navegador→Server propio (guarda la key)→Vercel AI Gateway→Jev
  • Jev va como una compuerta antes de actuar: decide, y tu código compara la probabilidad con el umbral.
  • Fijá la versión del modelo (typesafe-ai/jev-1.14.0) para que el umbral calibrado no cambie solo.
  • Límite de gasto, timeout y un log de decisiones sin datos personales.
